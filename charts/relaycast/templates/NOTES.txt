First run: create a workspace through the in-cluster admin API. The internal
secret never leaves the pod; the response holds the only copy of the workspace
key (rk_live_...), so store it in your secret manager:

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "relaycast.fullname" . }} -- node -e '
    const s = require("fs").readFileSync("{{ include "relaycast.secretMountPath" . }}/internal-secret", "utf8").trim();
    fetch("http://127.0.0.1:{{ .Values.server.port }}/internal/workspaces", { method: "POST",
      headers: { authorization: "Bearer " + s, "content-type": "application/json" },
      body: JSON.stringify({ name: process.argv[1] }) })
      .then(async (r) => { process.stdout.write(await r.text() + "\n"); process.exitCode = r.status === 201 ? 0 : 1; });
  ' my-team > workspace.json
